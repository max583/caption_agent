# Настройки

Где задаются параметры языковой модели и системные настройки.

## Для начинающих

Страница «Настройки» открывается по ссылке «Настройки» в навигационной строке. Слева — меню разделов, справа — содержимое выбранного раздела.

Разделы:
- **LLM** — адрес сервера и параметры языковой модели.
- **Повторные попытки** — лимиты на количество попыток нормализации.
- **Интервалы опроса** — как часто интерфейс обновляет данные.
- **Пути** — настройки путей к файлам.
- **Журналирование** — уровень логов и хранение.
- **База данных** — информация о базе данных и инструменты обслуживания.
- **Интерфейс** — язык интерфейса.

Большинство параметров хранятся в базе данных и применяются немедленно без перезапуска.

> **Совет:** для начала работы достаточно настроить только раздел «LLM» — задать адрес вашего сервера моделей и выбрать модель. Остальные параметры можно оставить по умолчанию.

## Для опытных пользователей

### Раздел LLM

Основной блок задаёт глобальный сервер и модель. Дополнительные блоки (Аналитик / Нормализатор / Интеллект. проверка) позволяют использовать отдельные конфигурации для каждого шага пайплайна. Поля, оставленные пустыми в блоках шагов, наследуются из основного блока.

Профили LLM позволяют сохранять и быстро переключать конфигурации. Активный профиль показывается в индикаторе в навигационной строке.

### Тест соединения

Кнопка «Проверить соединение» в разделе LLM отправляет тестовый запрос к модели и показывает задержку в миллисекундах. Ту же кнопку 🔌 можно использовать прямо из навигационной строки.

### Раздел «База данных»

Показывает размер файла базы данных, количество записей и предоставляет инструменты обслуживания: очистку старых записей журнала, вакуумирование SQLite.

Подробное описание параметров — в разделе [Настройки LLM](ref_llm_settings.md).
