# Страница «Проекты»

Главная точка входа в приложение: список проектов и рабочее пространство проекта.

## Для начинающих

При открытии Caption Agent вы попадаете на страницу «Проекты». Здесь показан список всех созданных проектов. Один проект — одно LoRA.

### Создание проекта

Нажмите кнопку «+ Создать проект». В форме укажите:

- **Название** — произвольное имя, например `Мой персонаж v001`.
- **Описание** — необязательно, для собственных заметок.
- **Тип LoRA** — что вы обучаете: персонаж, стиль, одежда и т.д.
- **Базовая модель** — семейство модели, например `flux` или `sdxl`.

После создания вы попадаете на страницу проекта.

### Страница проекта

Здесь три основных блока:

1. **Карточка проекта** — название, trigger token, тип LoRA, базовая модель. Кнопка «Редактировать» позволяет изменить эти параметры.

2. **Анализ датасета** — сворачиваемая панель с рекомендациями по составу батчей. Загружается по клику.

3. **Caption policy** — сворачиваемая панель с настройками правил подписей для этого проекта.

4. **Список батчей** — все батчи проекта с их текущим состоянием. Кнопка «Создать батч» открывает форму создания нового батча.

### Создание батча

В форме создания батча укажите:

- **Название** — например `iter1_portraits`.
- **Папка с изображениями** — путь к папке на вашем компьютере. Кнопка «Обзор» открывает проводник.

После создания батч появляется в списке и сразу помещается в очередь на обработку.

## Для опытных пользователей

Проект — верхний уровень иерархии: один проект = один trigger token = одно LoRA. Все батчи проекта наследуют его trigger token и тип LoRA.

Удаление проекта каскадно удаляет все батчи и записи изображений из базы данных. Исходные файлы и уже экспортированные `.txt`-файлы при этом не затрагиваются.

Анализ датасета — агрегированная статистика по всем завершённым батчам проекта. Предупреждения формируются на основе распределения атрибутов в принятых подписях.

## Влияние на рабочий процесс

Trigger token и тип LoRA нельзя изменить если у проекта уже есть обработанные батчи с принятыми подписями — это привело бы к несогласованности данных. Создайте новый проект, если нужно изменить эти параметры.

Подробнее о рабочем пространстве батча — в разделе [Рабочее пространство батча](ui_batch.md).
