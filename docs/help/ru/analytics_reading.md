# Как читать рекомендации

Что означают рекомендации по составу датасета и как действовать.

## Для начинающих

После нажатия на панель «Анализ датасета» вы видите список рекомендаций. Каждая выглядит примерно так:

> **Добавьте изображения в полный рост**
> В датасете 80% портретных кадров и только 5% изображений в полный рост. Это может привести к тому, что модель не будет корректно воспроизводить тело персонажа ниже плеч.

Рекомендации сформированы по трём уровням приоритета:
- **Высокий** — серьёзный дисбаланс, который, скорее всего, повлияет на качество обучения.
- **Средний** — нежелательное смещение, которое стоит исправить.
- **Низкий** — полезное улучшение, но не критичное.

Не нужно выполнять все рекомендации сразу. Начните с высоко-приоритетных.

## Для опытных пользователей

Рекомендации строятся на основе распределений по четырём осям: кадрирование, ракурс, состояние одежды, поза. Языковая модель также читает выборку из 20 подписей — это позволяет поймать смысловые смещения, не видимые в счётчиках.

### Типичные проблемы и их интерпретация

**Кадрирование.** Датасет с преобладанием портретов (portrait / head-and-shoulders) может обучить модель хорошо воспроизводить лицо, но плохо — тело. Для character LoRA нужен баланс: портреты, кадры по пояс (waist portrait) и полный рост (fullbody).

**Ракурс.** Преобладание фронтальных снимков (front view) приведёт к тому, что модель будет «поворачивать» персонажа во фронт при любом запросе. Добавьте снимки с 3/4 угла, профиль, вид сзади.

**Состояние одежды.** Если все изображения с одним и тем же типом одежды — модель рискует «привязать» эту одежду к trigger token. Разнообразие обязательно.

**Поза.** Статичные позы «стоит прямо» во всём датасете ограничат выразительность модели. Добавьте динамику.

**Предупреждения.** Большое число предупреждений STYLE_TOKEN или IDENTITY_OVERCAPTION говорит о системной проблеме с промптом или политикой подписей — стоит разобраться, прежде чем добавлять изображения.

### Когда рекомендации не применимы

- Для style LoRA рекомендации по кадрированию менее релевантны — там важна не структура кадра, а разнообразие стилей.
- Если датасет специально однороден (например, только референс-снимки одного ракурса) — рекомендация о разнообразии может быть намеренно проигнорирована.

Подробнее об анализе — в разделе [Анализ датасета](analytics_overview.md).
