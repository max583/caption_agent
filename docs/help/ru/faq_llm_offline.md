# Что делать если LLM не отвечает?

**Батч не обрабатывается. В журнале ошибки соединения с языковой моделью.**

## Прямой ответ

Сервер языковой модели недоступен: выключен, не запущен или адрес задан неверно.

## Пошаговое решение

1. Откройте раздел «Настройки» → «LLM».
2. Нажмите «Проверить соединение» (или кнопку 🔌 в навигационной строке).
3. Если тест вернул ошибку — убедитесь, что ваш сервер моделей запущен.
4. Проверьте поле `base_url`: по умолчанию `http://localhost:1234/v1`. Если ваш сервер слушает другой порт — исправьте.
5. Убедитесь, что `model_id` соответствует модели, загруженной на сервере.
6. Нажмите «Сохранить» после изменений и повторите тест.

Если тест прошёл успешно — пайплайн возобновится автоматически при следующей попытке обработки. Если батч завис — нажмите «Пауза», затем «Продолжить».

## Если сервер доступен, но ошибки продолжаются

- Проверьте журнал: раздел «Журнал» → фильтр по уровню ERROR → найдите запись с кодом ошибки.
- Увеличьте `request_timeout` (по умолчанию 600 секунд) — некоторые модели на медленном железе отвечают медленнее.
- Включите `debug_dump_llm_io` в разделе «Настройки» → «Журналирование» — сырые запросы и ответы запишутся в файлы для диагностики.
