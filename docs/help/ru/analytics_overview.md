# Анализ датасета

Аналитика оценивает сбалансированность датасета и даёт конкретные советы по исправлению состава — чтобы вы знали, каких изображений не хватает перед следующей итерацией генерации.

## Для начинающих

На странице проекта есть сворачиваемая панель «Анализ датасета». Нажмите на неё — Caption Agent посчитает распределение изображений по ключевым характеристикам и языковая модель сформулирует до пяти рекомендаций.

Набор анализируемых характеристик зависит от типа LoRA. Например, для character LoRA:
- **Кадрирование** — сколько изображений в полный рост, по пояс, портретных.
- **Ракурс** — спереди, сбоку, сзади, другие.
- **Поза** — распределение по описаниям позы.
- **Мимика** — выражения лица.
- **Состояние одежды** — одет, голые плечи, нижнее бельё, обнажён.

Для style LoRA вместо позы и одежды анализируются `style descriptor`, `medium/technique`, `lighting mood`. Для clothing LoRA — тип гармента, крой, материал.

Помимо этого всегда отображаются:
- **Тип источника** — синтетика против референса.
- **Предупреждения** — какие коды чаще всего встречаются.

В результате вы получаете конкретные советы: «добавьте изображения в полный рост», «слишком много фронтальных ракурсов», «недостаточно вариантов освещения».

## Для опытных пользователей

Анализ работает в два прохода:

**Первый проход (без LLM)** — статистика по принятым и ожидающим ревью изображениям всего проекта. Характеристики читаются напрямую из структурированного вывода аналитика (`raw_analyst_output`). Набор полей зависит от типа LoRA: для character — crop, camera_angle, pose, expression, clothing; для style — style_descriptor, medium_technique, lighting_mood; и так далее. Состояние одежды для character классифицируется из свободного текста по фиксированным категориям.

**Второй проход (LLM)** — языковая модель получает сводную статистику и до 20 примеров подписей. На основе этого она формирует до пяти рекомендаций с полями `priority`, `area`, `message`, `suggestion`. Промпт параметризован типом LoRA: рекомендации для character LoRA отличаются от рекомендаций для style LoRA.

Анализ учитывает только изображения в состоянии APPROVED и AWAITING_REVIEW — изображения в ERROR или DROPPED не считаются.

Рекомендации — это диагностика, не блокировки. Они не влияют на возможность экспортировать датасет.

## Влияние на рабочий процесс

Запускайте анализ перед следующей итерацией генерации изображений. Рекомендации подскажут, каких типов изображений не хватает, чтобы обучение было сбалансированным.

Подробнее о том, как читать рекомендации — в разделе [Как читать рекомендации](analytics_reading.md).
