# Обзор интерфейса

Общая структура интерфейса Caption Agent.

## Для начинающих

Caption Agent открывается в браузере по адресу `http://127.0.0.1:8765`. Интерфейс тёмный. В верхней части находится строка навигации, которая присутствует на каждой странице.

### Строка навигации

Слева — логотип «Caption Agent», он же ссылка на главную страницу.

Справа — ряд элементов:

- **Индикатор LLM** — показывает имя активного профиля и идентификатор модели. Цветная точка: зелёная — соединение проверено, красная — ошибка, серая — статус неизвестен. Кнопка 🔌 рядом выполняет быстрый тест соединения с языковой моделью.
- **Проекты** — переход к списку проектов.
- **Настройки** — настройки LLM и системы.
- **Журнал** — лог событий обработки.
- **?** — справочный раздел (эта страница).
- **Переключатель языка** — переключает интерфейс между русским и английским.

### Основное содержимое

Ниже навигации — основная рабочая область. Содержимое зависит от текущей страницы.

Всплывающие сообщения (toast) появляются в правом нижнем углу: они сообщают об успешных действиях или об ошибках.

## Для опытных пользователей

Интерфейс построен на HTMX + Alpine.js. Большинство обновлений происходят через HTMX: изменившаяся часть страницы обновляется без полной перезагрузки. Состояние навигации определяется по полному HTML-ответу.

Интервалы автообновления настраиваются в разделе «Настройки» → «Интервалы опроса». Страница проекта обновляется каждые 15 секунд, рабочее пространство активного батча — каждые 7 секунд.

Язык интерфейса хранится в базе данных и применяется ко всем страницам. Переключение языка делается кнопкой `RU / EN` в навбаре.

## Влияние на рабочий процесс

Большинство действий выполняются прямо на соответствующей странице — без дополнительных диалогов и модалок. Кнопки подтверждения появляются только для деструктивных действий (удаление проекта, батча, очистка лога).
