# Trigger token

Что такое trigger token и почему он стоит первым в каждой подписи.

## Для начинающих

Trigger token — уникальное слово, которое вы назначаете своему LoRA. Когда вы позже пишете его в запросе при генерации, модель понимает: «нужно активировать то, чему меня учили».

Например, если ваш trigger token — `mychar01`, все обучающие подписи начинаются с него:

```
mychar01, поясной портрет, вид спереди, синяя джинсовая куртка, городская улица
```

Модель видит тысячи изображений, каждое из которых начинается с `mychar01`. Она начинает связывать это слово со всем, что постоянно присутствует в изображениях, — то есть с самим объектом обучения.

> **Важно:** trigger token должен быть уникальным — такого слова не должно быть в обычном словаре модели. Обычные слова уже несут значение и будут вмешиваться в обучение. Используйте придуманные слова или сочетания букв и цифр: `mychar01`, `xstyle22`, `lora_fox`.

## Для опытных пользователей

Trigger token — это текстовый якорь для активации весов адаптера LoRA. Присутствие токена в обучающей подписи у каждого изображения обеспечивает атрибуцию всех визуальных признаков, общих для датасета, на этот токен через механизм текстового обусловливания.

Важно: токен должен находиться вне распределения базовой модели (out-of-distribution). Слова из словаря модели имеют сложившиеся эмбеддинги; токенизатор разобьёт их на знакомые подтокены и «разбавит» сигнал.

Оптимальный выбор — короткое слово без смысла в базовой модели. Нижнее подчёркивание, цифры и необычные буквосочетания снижают вероятность коллизии с существующими токенами. Пробелы в token недопустимы — он должен быть одним токеном.

Caption Agent автоматически добавляет trigger token в начало каждой подписи. Изменить его можно в настройках проекта — но только до начала обучения. После обучения смена токена делает LoRA нерабочей для генерации.

## Влияние на рабочий процесс

Быстрая проверка (rule checker) контролирует наличие trigger token в каждой подписи. Если он отсутствует, подпись не пройдёт проверку и нормализатор переписывает её.

Trigger token проекта задаётся в настройках проекта. Подробнее — в разделе [Параметры проекта](ref_project_params.md).
