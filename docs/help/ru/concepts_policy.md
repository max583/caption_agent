# Caption policy

Как проект управляет правилами подписей через caption policy.

## Для начинающих

Caption policy — набор настраиваемых правил для конкретного проекта. Эти правила уточняют, что нормализатор должен писать в подписях, а что быстрая проверка должна считать нарушением.

По умолчанию для каждого нового проекта применяются стандартные правила — они подходят для большинства случаев. Но если вы обучаете LoRA для конкретного персонажа или стиля, вы можете указать точные характеристики этого персонажа, которые нельзя называть в подписях, или конкретные фразы описания обстановки, которые чрезмерно детализированы.

Caption policy задаётся на странице проекта в сворачиваемой панели «Caption policy». Изменения применяются к следующим батчам.

## Для опытных пользователей

Caption policy состоит из шести полей:

**Структурированные поля** (читаются быстрой проверкой как машинночитаемые данные):
- `identity_trait_patterns` — регулярные выражения признаков идентичности. Если хотя бы одно совпадает в подписи — генерируется предупреждение IDENTITY_OVERCAPTION.
- `setting_overspecific_phrases` — список фраз обстановки. Если фраза встречается в подписи синтетического изображения — генерируется предупреждение SETTING_OVERSPECIFIC.
- `source_ref_required_setting` — обязательная фраза в подписях к референс-изображениям. По умолчанию: `gray studio background`.

**Поля свободного текста** (инжектируются в промпты LLM):
- `coarse_setting_note` — инструкция нормализатору о том, как описывать обстановку. По умолчанию задаёт принцип «2–4 слова, категория места, без специфичных деталей».
- `custom_normalizer_rules` — дополнительные правила для нормализатора. Приписываются в конец системного промпта.
- `custom_checker_rules` — дополнительные правила для интеллектуальной проверки.

Проект без явной caption policy (значение NULL в базе данных) использует значения по умолчанию. Это означает обратную совместимость: существующие проекты ведут себя так же, как до введения policy.

## Влияние на рабочий процесс

При создании батча caption policy проекта читается один раз и используется для всего батча. Изменение policy не перерабатывает уже обработанные изображения — только следующие батчи.

Подробнее о параметрах — в разделе [Параметры caption policy](ref_policy_params.md).
