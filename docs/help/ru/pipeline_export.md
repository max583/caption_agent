# Экспорт

Финальный шаг: запись принятых подписей в файлы рядом с изображениями.

## Для начинающих

После того как вы прошли ревью и приняли подписи, нажмите кнопку «Экспортировать» в рабочем пространстве батча.

Caption Agent запишет рядом с каждым изображением текстовый файл с тем же именем, но расширением `.txt`. Если изображение называется `portrait_001.jpg`, файл подписи будет называться `portrait_001.txt`.

Именно эти `.txt`-файлы читает тренер LoRA при обучении.

> **Важно:** принимаются при экспорте только изображения в состоянии «Принято» (APPROVED). Пропущенные и отклонённые изображения не экспортируются.

## Для опытных пользователей

Экспорт пишет в `.txt`-файл поле `final_caption` записи изображения. Если `final_caption` пустой — изображение пропускается.

Файлы пишутся рядом с исходными изображениями — в той же папке, которая была указана при создании батча. Экспортёр не создаёт подпапок и не перемещает исходные файлы.

Уже существующие `.txt`-файлы перезаписываются. Это позволяет переэкспортировать батч после ревью без ручной очистки.

Экспортируется только APPROVED-состояние. Изображения в AWAITING_REVIEW, ERROR или DROPPED — не экспортируются, даже если у них есть `normalized_caption`.

После экспорта батч переходит в состояние DONE.

## Влияние на рабочий процесс

Структура файлов после экспорта:

```
images/
  portrait_001.jpg
  portrait_001.txt   ← экспортированная подпись
  portrait_002.jpg
  portrait_002.txt
  ...
```

Большинство тренеров LoRA (ai-toolkit, kohya, SimpleTuner) автоматически находят `.txt`-файлы рядом с изображениями. Никакой дополнительной обработки не нужно.

Подробнее о ревью и принятии подписей — в разделе [Рабочее пространство батча](ui_batch.md).
