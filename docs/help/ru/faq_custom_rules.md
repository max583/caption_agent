# Как добавить свои правила?

**Нормализатор или интеллектуальная проверка систематически не учитывают что-то специфичное для моего проекта.**

## Прямой ответ

Caption policy позволяет добавить дополнительные инструкции прямо в промпты — без изменения базового кода.

## Пошаговое решение

### Если нужна новая инструкция для нормализатора

1. Откройте страницу проекта.
2. Раскройте панель «Caption policy» → нажмите «Редактировать».
3. В поле «Дополнительные правила нормализатора» напишите инструкцию на английском языке. Например:
   - `Always describe the character's hair as "dark brown hair" — never write "black hair".`
   - `If the character is wearing a hat, always specify its color.`
4. Сохраните.

Инструкция будет добавлена в конец системного промпта нормализатора при следующей обработке.

### Если нужно, чтобы интеллектуальная проверка ловила специфическое нарушение

1. В той же панели «Caption policy» заполните поле «Дополнительные правила проверки».
2. Опишите, что считается нарушением и почему. Например:
   - `Flag any caption that mentions "blue eyes" — the character's eyes are grey.`
3. Сохраните.

### Если нужно запретить конкретные фразы через быструю проверку

Для этого используйте структурированные поля:
- **Паттерны признаков идентичности** — добавьте регулярное выражение для запрещённой фразы.
- **Фразы избыточной конкретности обстановки** — добавьте конкретную фразу описания фона.

Эти поля читаются быстрой проверкой без LLM — быстро и без дополнительных расходов.

## Важное замечание

Изменения в caption policy применяются только к следующим батчам. Уже обработанные изображения не перерабатываются автоматически. Чтобы перегенерировать подпись для конкретного изображения — нажмите «Повторить» при ревью.
