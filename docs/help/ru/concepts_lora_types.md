# Типы LoRA

Что определяет тип LoRA и как он влияет на то, что попадает в подписи.

## Для начинающих

Caption Agent поддерживает семь типов LoRA. Тип выбирается один раз при создании проекта и определяет, что пайплайн считает важным при описании изображений.

| Тип | Что обучается |
|---|---|
| **Персонаж** | Идентичность конкретного человека: лицо, поза, одежда, обстановка |
| **Существо** | Идентичность персонажа-животного или фантастического существа |
| **Стиль** | Художественный стиль: техника, палитра, качество света, текстура |
| **Одежда** | Конкретный предмет гардероба: крой, ткань, цвет, конструктивные детали |
| **Поза** | Конкретная поза или движение: положение конечностей, распределение веса |
| **Объект** | Конкретный физический предмет: форма, материал, отделка |
| **Лицо** | Портрет: выражение лица, ракурс, освещение лица |

Если вы обучаете LoRA на конкретного персонажа — выбирайте «Персонаж». Для художественного стиля — «Стиль». Для специфической одежды — «Одежда».

## Для опытных пользователей

Тип LoRA управляет тем, что считается учебным сигналом, а что — шумом, который нужно контролировать в подписях.

**Персонаж и Существо** — цель обучения: идентичность. Стабильные черты (цвет глаз, форма носа, цвет шерсти, точный узор) в подписи не включаются — они усваиваются через визуальное повторение. В подписи: кадрирование, ракурс, одежда, поза, обстановка.

**Стиль** — цель обучения: визуальная обработка. Слова, описывающие стиль (акварельный, фотореалистичный, кинематографичный), обязательны — они и есть учебный сигнал. Качественные теги (шедевр, потрясающий, удостоен наград) запрещены.

**Одежда** — цель обучения: конкретный предмет гардероба. В отличие от персонажного LoRA, здесь детальное описание одежды обязательно: каждый атрибут (крой, ткань, цвет, конструктивные детали) выносится в отдельный слот. Носитель — только контекст для посадки, не предмет описания.

**Поза** — цель обучения: положение тела. Описание позы должно быть детальным: положение конечностей, вектор движения. Выражение лица, освещение, стабильные черты — не включаются.

**Объект** — цель обучения: физический предмет. В подписи: тип объекта, материал, цвет, видимые конструктивные детали. Ракурс камеры не включается. Качественные суждения (изящный, красивый) запрещены.

**Лицо** — цель обучения: портретная идентичность. Обязательно: кадрирование, ракурс, выражение лица, освещение. Одежда и обстановка — только если явно видны в кадре.

> **Важно:** у каждого типа есть риски привязки данных. Например, для стиля — если все изображения показывают один и тот же вид сюжета, LoRA свяжет стиль с этим сюжетом. Раздел аналитики предупреждает об этих рисках автоматически.

## Влияние на рабочий процесс

Тип LoRA нельзя изменить после создания проекта. Он определяет правила нормализатора, набор активных проверок и подсказки аналитику. При смене предметной области создавайте новый проект.
