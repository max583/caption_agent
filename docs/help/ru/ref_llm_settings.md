# Настройки LLM

Параметры языковых моделей, используемых в пайплайне. Находятся в разделе «Настройки» → «LLM».

## Для начинающих

Caption Agent использует языковые модели на трёх шагах пайплайна: аналитик, нормализатор и интеллектуальная проверка. Каждый шаг может работать с отдельной моделью или со одной общей.

В разделе «LLM» вы задаёте:
- Адрес и параметры основного сервера моделей.
- При необходимости — отдельные настройки для каждого шага.

Caption Agent работает с любым OpenAI-совместимым сервером: LM Studio, Ollama, vLLM, Jan и другими.

## Для опытных пользователей

### Основной блок LLM

| Параметр | По умолчанию | Описание |
|---|---|---|
| `base_url` | `http://localhost:1234/v1` | Базовый URL OpenAI-совместимого сервера |
| `api_key` | пусто | API-ключ. Можно задать через переменную окружения `CAPTION_AGENT_LLM_API_KEY` |
| `model_id` | `qwen3.6-35b-a3b` | Идентификатор модели, передаётся как `model` в запросах |
| `context_length` | `0` | Максимальный контекст (0 = авто) |
| `max_tokens` | `0` | Максимальное число токенов ответа (0 = без ограничений; для thinking-моделей используйте 0) |
| `temperature` | `0.2` | Температура генерации |
| `request_timeout` | `600` | Таймаут запроса в секундах |
| `max_retries` | `4` | Количество повторных попыток при ошибке сети или парсинга |

### Переопределения по шагам

Каждый шаг (аналитик / нормализатор / интеллектуальная проверка) имеет отдельный блок переопределений. Поля, оставленные пустыми, наследуются из основного блока. Заполненные поля переопределяют основной блок только для этого шага.

Переменные окружения для ключей по шагам:
- `CAPTION_AGENT_ANALYST_LLM_API_KEY`
- `CAPTION_AGENT_NORMALIZER_LLM_API_KEY`
- `CAPTION_AGENT_CHECKER_LLM_API_KEY`

### Профили LLM

LLM-настройки можно сохранять как именованные профили. Один профиль может быть помечен как «активный» — он применяется пайплайном. Профили удобны для переключения между разными серверами или моделями без ручного заполнения полей.

### Раздел «Повторные попытки»

| Параметр | По умолчанию | Описание |
|---|---|---|
| `normalizer_max_self_retries` | `3` | Максимум итераций нормализатора при наличии замечаний от быстрой проверки |
| `consecutive_failure_threshold` | `10` | Число последовательных ошибок батча, после которого пайплайн останавливается |

### Раздел «Интервалы опроса»

Как часто интерфейс обновляет данные (в секундах).

| Параметр | По умолчанию |
|---|---|
| Список проектов | `30` |
| Страница проекта | `15` |
| Батч в процессе обработки | `7` |
| Батч в неактивном состоянии | `30` |

### Раздел «Журналирование»

| Параметр | По умолчанию | Описание |
|---|---|---|
| `business_log_retention_days` | `30` | Хранение бизнес-лога (дни) |
| `debug_dump_llm_io` | выкл | Запись сырых запросов/ответов LLM в файлы (для отладки) |
| `log_level` | `INFO` | Уровень системного лога: DEBUG / INFO / WARNING / ERROR |
