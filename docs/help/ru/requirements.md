# Требования к окружению

Что нужно установить на компьютер, прежде чем запустить Caption Agent.

## Для начинающих

Caption Agent — это веб-приложение, которое работает на вашем компьютере. Для его запуска нужны Python и несколько стандартных инструментов. Браузер у вас уже есть.

**Что нужно:**

- **Python 3.10 или новее** — язык, на котором написано приложение. Скачать с [python.org](https://www.python.org/downloads/).
- **pip** — менеджер пакетов Python. Входит в стандартную установку Python.
- **Git** (опционально) — если вы хотите клонировать репозиторий. Альтернатива — скачать архив.

Приложение работает на Windows, macOS и Linux. Специальных требований к железу нет — GPU не нужен для самого Caption Agent. GPU нужен только если вы запускаете LLM локально.

## Для опытных пользователей

Caption Agent требует Python 3.10+ (используются `match`-операторы и типизированные mapped columns SQLAlchemy 2.0).

**Зависимости (устанавливаются автоматически через pip):**

| Пакет | Минимальная версия | Назначение |
|---|---|---|
| fastapi | 0.110 | Web framework |
| uvicorn | 0.27 | ASGI server |
| sqlalchemy | 2.0 | ORM |
| alembic | 1.13 | DB migrations |
| pydantic | 2.0 | Validation / schemas |
| httpx | 0.27 | LLM HTTP client |
| Pillow | 10.0 | Image metadata |
| markdown | 3.6 | Help rendering |

**LLM-эндпоинт** — обязательно. Любой OpenAI-совместимый API: локальный (LM Studio, Ollama, llama.cpp server) или облачный. Для шага анализа изображений нужна vision-модель. Для нормализатора и checker'а достаточно текстовой модели.

**База данных** — SQLite (по умолчанию, без настройки) или PostgreSQL (опциональный extra `[postgres]`).

## Проверка

Проверить версию Python:

```
python --version
```

Должно вывести `Python 3.10.x` или выше. Если выводит `Python 2.x` — установите Python 3 отдельно.

Подробнее об установке и запуске — в разделе [Установка и запуск](launch.md).
