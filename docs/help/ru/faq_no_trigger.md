# Почему caption начинается не с trigger token?

**Подпись должна начинаться с trigger token проекта, но этого не происходит.**

## Прямой ответ

Нормализатор забыл поставить trigger token в начало подписи. Быстрая проверка заметила это (код TRIGGER_MISSING) и попросила переделать, но либо все попытки были исчерпаны, либо ошибка повторилась.

## Что делать

1. В рабочем пространстве батча откройте вкладку «Ревью».
2. Найдите изображение с предупреждением TRIGGER_MISSING.
3. Нажмите «Повторить» — нормализатор запустится ещё раз.
4. Если после повтора ошибка сохраняется — проверьте, правильно ли задан trigger token в настройках проекта.

## Почему это может происходить систематически

Если TRIGGER_MISSING встречается на многих изображениях, причина, скорее всего, одна из двух:

- **Модель слишком «творческая»**: повысьте температуру чуть ниже или смените модель. Некоторые модели плохо следуют строгим форматным требованиям.
- **Trigger token похож на обычное слово**: например, `person` или `man`. Смените trigger token на бессмысленную строку.
