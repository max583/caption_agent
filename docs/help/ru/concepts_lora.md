# Что такое LoRA и зачем нужны подписи

Почему качество обучающих подписей напрямую влияет на результат дообучения.

## Для начинающих

LoRA — это способ научить уже обученную диффузную модель чему-то новому, не переобучая её целиком. Вы показываете ей набор изображений — и она запоминает то, что в них общее.

Каждое изображение должно сопровождаться текстовым описанием — подписью. Это описание говорит модели, что именно она должна запомнить из этого изображения, а что — игнорировать как фон.

Если не подписывать изображения вовсе или подписывать их одинаково, модель запомнит всё подряд: и нужный объект, и обстановку, и освещение. Потом, при генерации, она будет воспроизводить всё это вместе — вы не сможете получить тот же объект в другой обстановке.

Хорошие подписи говорят модели: «вот что здесь постоянное, а вот что каждый раз разное». Постоянное она свяжет с trigger token. Разное — будет контролироваться через запрос при генерации.

## Для опытных пользователей

При дообучении через LoRA текстовые подписи управляют атрибуцией признаков. Атрибут, который встречается во всех изображениях, но не отражён в подписях, «прилипает» к trigger token — модель считает его неотъемлемым свойством объекта обучения.

Цель грамотного составления подписей — достичь максимального покрытия по контролируемым переменным (поза, одежда, обстановка, освещение), одновременно исключив из подписей стабильные идентификационные признаки (черты лица, цвет глаз, форма носа). Последние модель выучит через визуальное повторение — они не нуждаются в текстовом якоре.

Плохо составленные подписи дают предсказуемые артефакты:

- **Привязка к фону** — если все изображения сняты в одной обстановке, а обстановка не отражена в подписи, модель свяжет её с trigger token.
- **Привязка к одежде** — если одежда детально описана для всех изображений, модель будет воспроизводить её даже когда вы этого не просите.
- **Размытие идентичности** — если подписи описывают нейтральный общий случай, а не конкретный объект, модель выдаёт правдоподобный, но не тот объект.

Caption Agent автоматически контролирует эти риски через набор правил, специфичных для типа LoRA.

## Влияние на рабочий процесс

Caption Agent формирует подписи по правилам, заданным для вашего типа LoRA. Вы проверяете результат и при необходимости корректируете — либо вручную, либо через настройки политики проекта.

Подробнее о типах LoRA — в разделе [Типы LoRA](concepts_lora_types.md). Подробнее о политике подписей — в разделе [Caption policy](concepts_policy.md).
