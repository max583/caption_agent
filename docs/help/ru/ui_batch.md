# Рабочее пространство батча

Где смотреть прогресс обработки и принимать решения по подписям.

## Для начинающих

Нажав на батч в списке проекта, вы попадаете в его рабочее пространство. Страница разделена на три вкладки.

### Вкладка «Обзор»

Сводная статистика по батчу: сколько изображений в каком состоянии. Если идёт обработка — счётчик обновляется автоматически. Здесь же показывается таймер обработки с оценкой оставшегося времени.

Кнопки управления батчем:

- **Запустить** — поставить батч в очередь.
- **Пауза / Продолжить** — временно остановить и возобновить.
- **Экспортировать** — записать принятые подписи в файлы.

### Вкладка «Items»

Список всех изображений с их текущим состоянием. Для каждого изображения видны: миниатюра, текущее состояние, количество попыток нормализации и предупреждения от проверок. Можно раскрыть карточку изображения и посмотреть полную подпись.

### Вкладка «Ревью»

Основная рабочая вкладка после завершения обработки. Здесь показаны изображения, ожидающие вашего решения — по одному или постранично.

Для каждого изображения вы видите:
- Само изображение
- Предложенную подпись
- Предупреждения от проверок (если есть)

Ваши варианты действий:

| Действие | Когда использовать |
|---|---|
| **Принять** | Подпись верная, готова к экспорту |
| **Повторить** | Подпись неверная, нужно переделать |
| **Отклонить** | Изображение не нужно в датасете |
| **Пропустить** | Хочу вернуться к этому позже |

## Для опытных пользователей

Вкладка «Items» отображает все записи изображений независимо от состояния. Фильтрация по состоянию позволяет быстро найти изображения в ERROR для анализа причины сбоя.

Предупреждения от проверок — это не блокировки. Они сохраняются в записи изображения и видны при ревью. Вы принимаете финальное решение — принять подпись с предупреждением или запросить повтор.

Действие «Повторить» возвращает изображение на шаг нормализации. Аналитик при этом не перезапускается. Попытки нормализации после ревью-повтора учитываются отдельно от автоматических попыток.

Экспорт запускается вручную или при закрытии ревью. Он записывает принятые подписи как `.txt`-файлы рядом с исходными изображениями — в той же папке, что была указана при создании батча.

## Влияние на рабочий процесс

Страница автоматически обновляет состояние батча и список изображений пока идёт обработка. Никакой ручной перезагрузки не нужно.

Подробнее о состояниях изображений — в разделе [Жизненный цикл изображения](pipeline_image_lifecycle.md).
