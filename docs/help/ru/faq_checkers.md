# Чем быстрая проверка отличается от интеллектуальной?

**В рабочем пространстве батча есть предупреждения от двух разных источников. В чём разница?**

## Прямой ответ

Это два разных шага пайплайна, которые проверяют разные вещи.

**Быстрая проверка** (rule checker) — детерминированная, без LLM. Проверяет текст подписи по регулярным выражениям и правилам: есть ли trigger token, нет ли запрещённых слов, соответствует ли структура формату. Работает быстро, результат всегда одинаков для одного и того же текста.

**Интеллектуальная проверка** (LLM checker) — семантическая, через LLM. Проверяет, соответствует ли подпись изображению, нет ли скрытых нарушений политики, нет ли логических противоречий. Смотрит сразу на подпись и на данные аналитика.

## Что каждая проверяет

| Быстрая проверка | Интеллектуальная проверка |
|---|---|
| Trigger token в начале | Соответствие описания изображению |
| Style-токены | Неявные возрастные фразы |
| Запрещённые слова и фразы | Противоречия между полями |
| Наличие кадрирования и ракурса | Нарушения пользовательских правил |
| Структурная полнота подписи | Семантические несоответствия |

## Почему важны обе

Быстрая проверка — сеть безопасности для механических нарушений: она ловит ошибки формата быстро и без дополнительных расходов. Интеллектуальная проверка — последний барьер перед ревью: она ловит то, что регулярными выражениями не поймать.
