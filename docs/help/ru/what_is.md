# Что такое Caption Agent

Локальный инструмент для автоматического создания подписей к изображениям, которые используются при обучении LoRA.

## Для начинающих

Когда вы обучаете LoRA в Stable Diffusion или FLUX, каждое обучающее изображение должно иметь текстовое описание — caption. Чем точнее и последовательнее эти описания, тем лучше LoRA запомнит то, чему вы её учите.

Caption Agent делает эту работу за вас. Вы загружаете папку с изображениями, задаёте несколько настроек проекта — и инструмент автоматически описывает каждое изображение, проверяет описание по правилам и предлагает его вам на утверждение.

Caption Agent работает локально на вашем компьютере. Никакие изображения никуда не отправляются — кроме запросов к LLM, который вы сами настраиваете.

## Для опытных пользователей

Caption Agent — это pipeline для генерации training captions с детерминированным контролем качества. Главная задача: добиться distributional coverage нужных атрибутов при минимальном binding несущественных.

Каждое изображение проходит цепочку из четырёх шагов: структурированный анализ через vision LLM, нормализация в итоговую подпись, детерминированная проверка правил (без LLM), семантическая проверка через LLM. Результат отправляется на ручное ревью перед экспортом.

Инструмент поддерживает семь типов LoRA с разной логикой подписей: character, creature, style, clothing, pose, object, face. Каждый тип меняет то, что считается важным атрибутом, а что — шумом.

Caption policy — настраиваемый набор правил на уровне проекта — позволяет задать identity patterns, фразы настройки, правила нормализатора и checker'а без редактирования промптов.

## Влияние на рабочий процесс

Caption Agent не трогает ваши исходные файлы. Он читает изображения, создаёт подписи в базе данных, предлагает их на ревью. Только после вашего одобрения подписи экспортируются в `.txt`-файлы рядом с изображениями — в том формате, который принимают большинство трейнеров.
