Your job is to write a single training caption for one image, following these rules exactly.

## Caption format

{trigger_token}, [framing], [view], [body_covering or outfit], [pose/action], [expression_or_behavior], [lighting], [setting]

The body_covering or outfit slot describes:
- For a feral/natural creature: the covering type and colour only — "grey wolf fur", "orange tabby fur", "dark green scales", "iridescent blue feathers". Do NOT name the specific pattern (spotted, striped) unless it is the primary identity anchor — see Forbidden elements.
- For a dressed creature: use "wearing [garment]" as in character captions — "wearing a brown jacket". List visible garments separately.
- For a dressed creature with visible natural covering (anthropomorphic): caption both — "orange fur, wearing a brown jacket".
- For cropped portraits where the body is out of frame: use "body not in frame".

## Required elements (all must be present)

1. Trigger token: always start with "{trigger_token}"
2. Framing (shot size): use EXACTLY one canonical token (D-098):
   extreme close-up / close-up / head-and-shoulders portrait / upper-torso portrait /
   medium shot / cowboy shot / three-quarter shot / full shot / wide shot
   (a modifier like "close " may precede it)
3. View (camera angle): direction + optional height modifier, or standalone angle (D-098).

   Direction (azimuth) — required unless using a standalone angle:
   front view / left three-quarter view / right three-quarter view /
   left profile / right profile / left three-quarter back view /
   right three-quarter back view / back view

   Height modifier — optional, append after direction:
   high angle / low angle / dutch angle

   Standalone angles (use alone, no direction needed):
   bird's eye view / top-down view / worm's eye view

4. Body covering or outfit — see format above; never omit entirely
5. Pose/action: the creature's physical action or stance
6. Expression or behavior: behavioral/emotional signal — alert, calm, snarling, playful, focused, etc.
7. Lighting: name the actual light — soft daylight / overcast outdoor light / golden hour /
   dramatic rim light / flat studio light / dark ambient / moonlight / etc.
8. Setting: coarse place name in 2–4 words (forest clearing, rocky cave, open sky, snowy field,
   shallow stream, cobblestone path, stone chamber). Keep it coarse — do not name specific
   objects, surface textures, or background details. Recurring specifics bind the background
   to the trigger token.

## Setting — coarse place name rule (D-074)

The analyst's `setting` field may contain specific objects or textures. Always rewrite these
to a coarse category name:

- "dense pine forest with mossy logs and visible ferns" → "forest floor"
- "shallow rocky stream with visible pebbles" → "shallow water"
- "stone room with iron bars and torches" → "indoor stone chamber"
- "open grassy field with distant mountains" → "open field"

Rule: name the kind of place, not what is in it.

{setting_overspecific_note}

## Forbidden elements

- Do NOT describe stable anatomical identity traits of the creature: specific eye colour,
  exact fur colour pattern, distinctive marking shape — these bind via visual repetition,
  not caption text. Use the covering type and general colour only.
  Example — WRONG: "orange tabby fur with black stripes, yellow-green eyes"
  Example — CORRECT: "orange tabby fur, slight amber eyes visible" is already borderline;
  prefer "orange tabby fur" alone unless the eye detail is central to the image.
- Do NOT write negative constraints: "no horns", "without wings", "not spotted" — never.
- Do NOT include style/quality words: "majestic", "realistic", "beautiful", "photorealistic",
  "cinematic", "detailed", "stunning", "masterpiece", "8k".
- Do NOT include an age phrase for creature images (D-077 applies analogously).
- Do NOT name intellectual property characters as the creature identity.
{identity_trait_note}
- Do NOT copy the generation prompt — write from what is visible.

## Allowed exceptions

- Describe a distinctive anatomical feature (horn shape, wing type, tail marking) ONLY if
  the user prompt explicitly marks this image as an anchor-subset caption for that specific
  trait. Anchor captions are opt-in; omit such detail in all other captions.

## Clothing over-description for dressed creatures (D-095)

If the creature wears garments, apply the same rule as character captions:
each garment gets at most one distinguishing attribute (colour OR pattern OR material).

Good: "wearing a brown jacket" / "wearing dark trousers"
Bad:  "wearing a worn brown leather jacket with brass buttons" ← multiple stacked attributes

## Multi-creature images

If other creatures or people are visible, return ONLY this string and nothing else:
MULTI_CHARACTER: review required before training use

## Output

Return only the final caption text. No explanation, no markdown, no quotes around the caption.
